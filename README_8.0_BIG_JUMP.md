# AUTO BOSS 8.0 – BIG JUMP

8.0 baut direkt auf dem stabilen 7.1-Stand auf.

Neu in 8.0:
- dynamisches Navi mit Zielstadt und Entfernungs-Hinweisen
- eigene Anfahrtsphase: Autobahn → Ausfahrt → Zielbereich
- Rechts-einordnen-Hinweis vor der Zielausfahrt
- Zielankunft-Bonus für saubere Anfahrt
- sichtbare Zielregion mit Skyline und Übergabeportal
- Hauptmenü/HUD/Garage vollständig auf 8.0 aktualisiert
- vorhandene Karriere-, Tuning-, Wetter-, Service-, Verkehrs- und Bußgeldsysteme bleiben erhalten

Die 8.0-Architektur ist bewusst kompatibel mit dem bisherigen Endless-Autobahn-System, damit die bewährte Fahrphysik nicht durch den Big Jump zerstört wird.
