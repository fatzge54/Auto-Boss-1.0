# AUTO BOSS 13.3 – Fleet Command

Diese Version baut direkt auf 13.2 auf.

## Neu
- Firmenzentrale komplett neu angeordnet, damit sich Texte und Buttons nicht mehr überlagern.
- Neues Menü **Disposition / Auto-Aufträge** mit sichtbaren Firmenrouten, Teams und prognostizierten Einnahmen.
- Firmen-/Flottenstatus kompakter und klarer dargestellt.
- Deutschland-Empire bleibt vollständig erhalten.
- Firmen-Autoaufträge laufen weiterhin nach jeder eigenen Lieferung und zahlen abhängig von Teams, Standorten und Disposition aus.
- Versionsanzeige auf 13.3 aktualisiert.

## Fokus für den Test
1. Firmenzentrale öffnen und auf Lesbarkeit prüfen.
2. Disposition / Auto-Aufträge öffnen.
3. Eine Fahrt abschließen und prüfen, ob Firmen-Autoaufträge und Firmenbonus in der Abrechnung erscheinen.
4. Standort-/Flotten-Upgrades testen.
