# AUTO BOSS 20.0 – HIGHWAY REVOLUTION

Weiterentwicklung von 19.0 ohne Reset von Karriere oder Savegame.

## Schwerpunkt dieses Builds
- Lärmschutzwände werden in großen Schutzbereichen um SERVICE SÜD, MITTE und NORD ausgespart, damit Tankstellen und Zufahrten nicht mehr verdeckt werden.
- Die großen blauen Autobahn-Portale aus 16.0 erhalten echte Ziel- und Entfernungsbeschriftungen.
- Die vorhandenen Motorway-Sign-Texte wurden zur Fahrtrichtung ausgerichtet, damit nicht mehr nur die leere Rückseite sichtbar ist.
- Jede Tankstelle erhält einen eigenen Service-Vorwegweiser.
- Zusätzliche Asphalt-Fahrspuren und Leitplankenpfosten erhöhen die Tiefenwirkung der Autobahn.
- Branding auf AUTO BOSS 20.0 / HIGHWAY REVOLUTION aktualisiert.

## Weiterhin kompatibel
Missionen, Karriere, Firmenzentrale, Deutschland-Empire und `user://autoboss.cfg` bleiben erhalten.
