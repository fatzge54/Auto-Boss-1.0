# AUTO BOSS 13.0 – BIG JUMP

Auf Basis der 12.3 Company-Management-Version.

BIG-JUMP-Systeme:
- Firmenimperium mit 5 Entwicklungsstufen
- bis zu 5 Niederlassungen
- Niederlassungen erhöhen automatische Firmenerträge
- Logistik-Rating
- Elite-Verträge mit großen Bonuszahlungen
- gesamter Firmenumsatz wird gespeichert
- bestehende Mitarbeiter-, Flotten-, Dispo-, Fahrerlevel- und Wartungssysteme bleiben erhalten
- bestehende Spielstände erhalten Standardwerte für neue 13.0-Felder

Wichtig: Das ist ein Ausbau der bestehenden stabilen Spielbasis und kein Austausch der Fahrphysik/3D-Welt.
