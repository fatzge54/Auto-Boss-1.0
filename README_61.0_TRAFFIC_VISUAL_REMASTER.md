# AUTO BOSS 61.0 – Traffic Visual Remaster

## Änderungen
- KI-Fahrzeuge erhalten bereits in der einfachen Fernansicht profilierte Karosserien statt reiner bunter Quader.
- LKW besitzen ein neutral-silbernes Anhänger-/Ladeabteil, eine andersfarbige Fahrerkabine und erkennbare Scheibe.
- Kompakte Van-, SUV- und Pkw-Silhouetten sowie vier gebündelte Räder pro Auto.
- Beim Detail-Upgrade wird der nächste, nicht der zuerst erzeugte Wagen bevorzugt.
- Bei hoher FPS-Anzeige sind bis zu acht detaillierte Verkehrsteilnehmer möglich; bei niedrigerer Bildrate bis zu fünf.
- Menü/HUD/Projekttitel/GitHub-Artefakt heißen 61.0.

## Upload auf GitHub
Den Inhalt des äußeren Verzeichnisses `Auto-Boss-1.0-main` ins Repository-Hauptverzeichnis übernehmen. Die vorhandenen `assets/graphics50`, `assets/graphics51` und `assets/graphics60` erhalten. Für Version 61.0 sind keine neuen Assetordner nötig.

## Zu testen
APK über GitHub Actions erstellen; bei Fehlern den Build-Log prüfen. Auf dem Samsung: farbige Kästen bei engem Verkehr, FPS bei Regen und 0 km/h, Nachtbeleuchtung, Unternehmensmenüs, Karrierespeicher. Die Änderungen wurden statisch geprüft, nicht auf Android ausgeführt.
