# AUTO BOSS 9.0 – BIG JUMP

9.0 baut direkt auf AUTO BOSS 9.0 auf und behält den bestehenden Spielstand (`user://autoboss.cfg`).

## Neu in 9.0
- Deutschland-Auftragszentrale auf 14 Routen erweitert
- neue VIP-Auftragsklasse für hohe Reputation
- Risiko-Anzeige pro Auftrag (Verkehr, Wetter, Zeitdruck, Extrem)
- Firmenfortschritt mit Firmenstufen und wachsendem Unternehmensnamen
- Karriere skaliert jetzt stärker mit abgeschlossenen Jobs
- Tuning von 3 auf 5 Stufen erweitert (Motor, Bremsen, ECO)
- Verkehrsdichte steigt mit dem Firmenlevel bis zu 22 KI-Fahrzeugen
- höhere XP-Belohnung für VIP-Überführungen
- Vergütungen der Aufträge neu balanciert
- Hauptmenü, Garage und HUD auf AUTO BOSS 9.0 aktualisiert
- alle Systeme aus 8.0 bleiben erhalten: Navi, Zielausfahrt, Wetter, Tag/Nacht, Blitzer, Bußgelder, Tankstellen, Werkstatt, Verkehr, Karriere und Speichern

## Kompatibilität
Der Save-Key bleibt `user://autoboss.cfg`. Ein vorhandener 8.0-Spielstand kann weiterverwendet werden.
