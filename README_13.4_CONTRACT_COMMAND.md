# AUTO BOSS 13.4 – Contract Command

13.4 baut direkt auf der stabilen 13.3 Fleet-Command-Version auf.

## Neu
- **Contract Command** als interaktive Disposition.
- Drei Firmenstrategien: **BALANCE**, **SICHERHEIT**, **MAX PROFIT**.
- Eine Schwerpunkt-Route kann direkt ausgewählt werden.
- Die Strategie verändert den automatischen Firmen-Ertrag.
- Flottenzustand beeinflusst jetzt die passive Firmenleistung.
- Erfolgreiche Firmenläufe bauen eine **Dispo-Serie** auf und steigern den Ertrag leicht.
- MAX PROFIT bringt mehr Geld, verursacht aber mehr Flottenverschleiß.
- SICHERHEIT reduziert den Ertrag etwas, schont dafür die Firmenflotte.
- Strategie, Schwerpunkt-Route und Serie werden im Spielstand gespeichert.
- Firmenzentrale und HUD auf **AUTO BOSS 13.4** aktualisiert.

## Test
1. Firmenzentrale → CONTRACT COMMAND öffnen.
2. Strategie mehrfach wechseln.
3. Eine freigeschaltete Route als Schwerpunkt auswählen (★).
4. Eine eigene Fahrt abschließen.
5. Firmen-Autoauftrag, Flottenzustand und Auszahlung kontrollieren.
