# AUTO BOSS 21.0 – GRAPHICS UPGRADE

Aufbauend auf Version 20.0, ohne Reset der Karriere oder Savegames.

## Änderungen
- Projektname in Godot auf 21.0 aktualisiert.
- Zusätzliche Reflektoren und Asphaltfugen entlang der Autobahn.
- Drei Rastplatz-Vorbereiche farblich hervorgehoben und mit Markierungen versehen.
- Zusätzliche Leitpfosten mit dunklen Reflexflächen an beiden Fahrbahnseiten.
- Vorhandene Schilder- und Lärmschutz-Fixes aus Version 20.0 bleiben erhalten.

Das Projekt wurde auf Quellcode-Ebene angepasst. Ein Godot-Laufzeittest bzw. Android-Build wurde hier nicht durchgeführt.
