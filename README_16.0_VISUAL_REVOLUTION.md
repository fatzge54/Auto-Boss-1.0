# AUTO BOSS 16.0 – VISUAL REVOLUTION

Großer Design-Sprung auf Basis von 15.0. Savegame `user://autoboss.cfg` bleibt kompatibel.

- komplett eigenständiger, nahezu blickdichter Premium-Homescreen statt störender 3D-Nahobjekte hinter dem Menü
- neue Hero-Fläche mit „Drive • Build • Dominate“, Live-Operations und Deutschland-Route
- Garage auf „16.0 Performance Studio“ umgestellt und visuell vom Fahrwelt-Hintergrund getrennt
- Autobahn mit regelmäßigem Leitpfosten-Rhythmus, zusätzlichen Portalrahmen und blauen Autobahntafeln
- dunklere Asphalt-Inlays für mehr Geschwindigkeit und Tiefenwirkung
- Versionsbranding in Hauptmenü, HUD, Deutschland-Empire und Contract Command auf 16.0 angehoben
- Karriere, Firma, Deutschland-Empire, Aufträge, Verkehr, Tuning und Savegame bleiben erhalten
