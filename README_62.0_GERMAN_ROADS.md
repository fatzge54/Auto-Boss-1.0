# AUTO BOSS 62.0 — GERMAN ROADS

**Neuer Open-World-Entwicklungszweig auf Basis des bestehenden Projekts 61.0.**

Neu: eine befahrbare 25 × 25 km Koordinatenwelt, 400-m-Sektor-Streaming, fünf deutsche Fantasiestädte, stufenweise zufällig erzeugte Landschaftsdetails, eine durchgehende befahrbare Straßenstruktur ohne Weg-Teleport, sechs Fahrzeugklassen, Verkehr, GPS, 44 Aufträge, Abhol-/Übergabehandlung, Abrechnung, Karriere, Geld, Ruf, Werkstatt, Unternehmen, Tageszeit und Wetterwirkung. Touchbedienung inklusive.

**Wichtig:** Weltgröße bedeutet nicht 625 km² individuell gestalteter Gebäude und Straßen. Die Welt ist derzeit ein technischer Prototyp. Ein richtiger Godot- und Android-Lauf steht noch aus.

- **Neue Spielszene:** `main.tscn`
- **Alte Version:** `legacy_main.tscn`
- **Technikdetails und Grenzen:** `docs/OPEN_WORLD_62_REALISIERUNG.md`
- **Android:** `.github/workflows/android-build.yml`

GitHub-Upload: **Inhalt** des Ordners `Auto-Boss-1.0-main` in das Repository hochladen, nicht den äußeren Ordner als Unterordner. Alte Unterordner `assets`, `scripts`, `tools` beibehalten und die neuen Dateien dazunehmen.
